# The Transformer Architecture

The Transformer, introduced by Vaswani et al. in 2017, replaced recurrence and convolution with a mechanism called self-attention as the primary tool for modeling relationships between elements of a sequence. Prior architectures such as RNNs and LSTMs processed tokens one at a time, which limited parallelization during training and made it hard to model long-range dependencies because information had to pass through many sequential steps. The Transformer instead lets every token attend directly to every other token in a single layer, so relationships between distant words are captured in one hop rather than many.

A Transformer block is built from two sub-layers: multi-head self-attention and a position-wise feed-forward network, each wrapped with a residual connection and layer normalization. Multi-head attention runs several attention operations in parallel, each with its own learned projections of queries, keys, and values, so that different heads can specialize in different kinds of relationships (for example, one head might track subject-verb agreement while another tracks coreference). The outputs of all heads are concatenated and linearly projected back to the model's hidden dimension.

Because self-attention has no inherent notion of token order, Transformers add positional information explicitly. The original paper used fixed sinusoidal positional encodings added to the input embeddings; later models introduced learned positional embeddings, relative position representations, and rotary position embeddings (RoPE), which encode position by rotating query and key vectors as a function of their position, improving extrapolation to longer sequences than seen during training.

The original architecture had an encoder stack and a decoder stack. The encoder produces contextualized representations of the input sequence, while the decoder generates output tokens autoregressively, attending both to previously generated tokens (via masked self-attention) and to the encoder's output (via cross-attention). Encoder-only models (like BERT) are well suited to understanding tasks such as classification and extraction, decoder-only models (like GPT-style LLMs) are well suited to open-ended generation, and encoder-decoder models (like T5) are used for sequence-to-sequence tasks such as translation and summarization.

The main computational cost of a Transformer is the self-attention operation, whose time and memory scale quadratically with sequence length because every token must be compared with every other token. This has motivated a large body of work on efficient attention variants (sparse attention, linear attention, sliding-window attention) and on systems-level optimizations such as FlashAttention, which restructures the attention computation to reduce memory reads and writes on the GPU without changing the mathematical result.
