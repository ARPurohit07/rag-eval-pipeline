# RLHF and Alignment

Reinforcement Learning from Human Feedback (RLHF) is a technique for adjusting a language model's behavior to better match human preferences, used after initial pretraining and supervised fine-tuning to make base language models into the helpful, instruction-following assistants deployed in production chat products. The core problem RLHF addresses is that "predict the next token" pretraining, and even instruction-tuning on example question-answer pairs, does not directly optimize for qualities humans actually want, like helpfulness, honesty, and harmlessness — those are properties of an entire response judged holistically, not something a token-level prediction loss captures directly.

The classic RLHF pipeline has three stages. First, supervised fine-tuning (SFT): the pretrained base model is fine-tuned on a smaller, high-quality dataset of example prompts and ideal responses, written or curated by humans, to establish a baseline instruction-following behavior. Second, reward model training: human annotators are shown multiple model outputs for the same prompt and rank them by preference; this preference data trains a separate reward model to predict a scalar score for how much a human would like any given response. Third, reinforcement learning: the SFT model is further optimized (commonly with an algorithm called PPO, Proximal Policy Optimization) to generate outputs that the reward model scores highly, while a penalty term (typically a KL-divergence constraint against the original SFT model) discourages the policy from drifting so far that it starts exploiting quirks of the reward model rather than genuinely improving — a failure mode known as reward hacking.

Direct Preference Optimization (DPO) is a more recent alternative that achieves a similar end goal without training a separate reward model or running reinforcement learning at all. DPO shows that the RLHF objective can be re-expressed as a classification-style loss directly over pairs of preferred and dispreferred responses, so the model can be trained on human preference data with ordinary supervised-learning-style gradient descent. This makes DPO considerably simpler to implement and more stable to train than full RLHF, and it has become a popular default for preference-tuning open models, though some practitioners still find PPO-based RLHF or hybrid approaches yield better results at the largest scales.

Alignment more broadly refers to the general goal of making a model's behavior match human intentions and values, of which preference-tuning (RLHF/DPO) is one major tool. Other techniques in this space include Constitutional AI, where a model is trained to critique and revise its own outputs against a written set of principles (reducing reliance on large volumes of human-labeled preference data), and red-teaming, where humans or other models deliberately probe a model for harmful, biased, or otherwise undesired outputs so those failure modes can be fixed before deployment. A model can be well-aligned to instructions in a narrow sense (it follows requests fluently) while still being poorly aligned in a deeper sense (it is unhelpful, sycophantic, or confidently wrong), which is part of why alignment evaluation typically requires multiple complementary methods rather than a single benchmark score.
