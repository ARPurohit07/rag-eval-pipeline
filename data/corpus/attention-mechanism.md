# Attention Mechanisms

Attention is a way for a model to compute a weighted combination of a set of values, where the weights are determined by how relevant each value is to a given query. In the scaled dot-product attention used by Transformers, every input token is projected into three vectors: a query (Q), a key (K), and a value (V). The attention score between a query and a key is their dot product, scaled by the square root of the key dimension to keep gradients stable, and then passed through a softmax so the scores for a given query sum to one. The output for that query is the weighted sum of all value vectors, using those softmax weights.

Self-attention is the special case where queries, keys, and values all come from the same sequence, so each token attends to every other token in that sequence, including itself. Cross-attention is the case where queries come from one sequence (for example, a decoder's partially generated output) and keys/values come from a different sequence (for example, an encoder's output), which is how encoder-decoder models condition generation on an input.

Multi-head attention splits the query, key, and value projections into several smaller subspaces ("heads"), runs scaled dot-product attention independently in each subspace, and concatenates the results. This lets the model attend to information from different representation subspaces at different positions simultaneously, rather than being forced to average all relevant signals into a single attention distribution per layer.

Causal (masked) self-attention is used in autoregressive decoders: a mask sets the attention score from position i to any position j > i to negative infinity before the softmax, so a token can only attend to itself and earlier tokens. This enforces that the model cannot "look ahead" at tokens it is supposed to predict, which is essential for training decoder-only language models with teacher forcing and for correct behavior during generation.

Attention weights are sometimes used for interpretability, on the intuition that high attention from token A to token B means B was influential in producing A's representation. This intuition is not fully reliable in deep, multi-layer, multi-head models, because information is mixed across many layers and heads and the residual stream carries forward information that never gets explicitly "re-attended" to. Attention weights are best treated as one diagnostic signal among several, not as a complete causal explanation of model behavior.

Key-value (KV) caching is an inference-time optimization for autoregressive decoding: since causal attention means past keys and values never change as new tokens are generated, they can be computed once and cached, so each new token only requires computing attention against the cached K/V pairs rather than recomputing them for the whole sequence. This is what makes token-by-token generation with large decoder-only models tractable in production.
